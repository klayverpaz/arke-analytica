Privacidade e informações legais

Atualizado em novembro de 2026.

O que este site coleta

Este site não usa cookies, analytics nem rastreadores, e não armazena os dados digitados no formulário de contato.

Formulário de contato

Ao enviar o formulário, o seu navegador abre o WhatsApp com uma mensagem contendo o que você preencheu: nome, empresa, e-mail, WhatsApp, descrição do desafio, prazo e, se informada, a faixa de investimento. O envio só acontece quando você confirma a mensagem no WhatsApp.

Usamos esses dados apenas para responder ao seu contato e avaliar o projeto. Eles não são vendidos nem compartilhados para fins de publicidade.

Serviços de terceiros

As fontes tipográficas são carregadas do Google Fonts e a página é hospedada no GitHub Pages. Esses serviços podem registrar dados técnicos de acesso, como endereço IP, segundo as políticas deles. As conversas pelo WhatsApp seguem os termos do próprio WhatsApp.

Seus direitos

Você pode pedir acesso, correção ou exclusão dos dados que nos enviou, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), escrevendo para arkeanalytica@gmail.com.
